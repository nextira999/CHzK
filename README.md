# CHzK

CHzK(이하 '치즈크' 혹은 '치직')은 마인크래프트 채팅에 치지직 생방송 채팅을 표시하는 모드입니다.

본 모드는 개발에 Ai가 활용되었습니다.

## 지원 기능

현재 지원하는 기능은 아래와 같습니다.

- 실시간 채팅 연동
- 후원 채팅 연동 (지원 예정)
- 구독 채팅 연동 (지원 예정)

## 지원 버전

현재 지원하는 버전은 아래와 같습니다.

지원 버전은 점차 늘려갈 예정입니다.

각 버전을 누르시면 해당 버전의 저장소 브런치로 이동합니다.

- [26.1~](https://github.com/nextira999/CHzK/tree/26.1)

## 사용 방법

명령어는 모두 `/chzk {명령어}`의 형태로 구성됩니다.

네트워크 연결이 필수입니다.

### 싱글 플레이

`set {채널 id}`로 채널의 ID를 설정합니다. 해당 ID는 영구적으로 로컬에 저장됩니다.

채널의 ID를 찾는 법은 아래를 참고해 주세요.

```text
1. 자신이 설정하고자 하는 채널로 들어갑니다.
2. 채널 페이지의 주소는 아래 형태와 같습니다. 
- https://chzzk.naver.com/abcde12345
- https://chzzk.naver.com/live/abcde12345
3. 여기에서 [abcde12345]가 채널의 ID입니다.
```

설정 후 `on`으로 채팅 서버에 연결합니다.

`off`로 연결을 해제합니다.

### 멀티 플레이

현재 정식적으로 지원을 하지 않으면, 테스트하지 않았습니다.
